# BorealLM

BorealLM is an experimental small-language-model project
investigating domain specialization under constrained consumer
hardware.

The first domain specialization, BorealLM-AM, focuses on
additive manufacturing.

## Research Question

How does domain-specific pretraining data composition affect
the technical knowledge and language modeling performance of
small transformer models under a fixed parameter and compute
budget?

## Hardware

Apple M5 Pro
16 GB unified memory
1 TB SSD

## Initial Model

BorealLM-AM-10M

## Initial Dataset

BorealAM-Micro

## Primary Evaluation

Additive Manufacturing Benchmark
Held-out domain perplexity
Tokenizer efficiency
Training efficiency
